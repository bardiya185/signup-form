# برنامه انتقال بک‌اند به لاراول (Roadmap)

> هدف: کل بک‌اند سایت (۱۱۱ مسیر `api/v1`) با **Laravel 12** پیاده‌سازی شود و تمام کالاها و داده‌ها از دیتابیس واقعی بیایند.

## وضعیت فازها

| فاز | شرح | وضعیت |
|---|---|---|
| ۱ | **دیتابیس واقعی زنده در همین محیط:** همه ۵۷ جدول روی SQLite روی دیسک (`data/ginankala.sqlite`) — سید کامل کاتالوگ، write-through اتمیک بعد از هر درخواست، ماندگاری بین ری‌استارت‌ها (تست‌شده) | ✅ انجام شد |
| ۲ | **اسکلت Laravel 12** در `backend/` + ۱۲ فایل Migration پوشش‌دهنده کامل ۵۷ جدول (تولید خودکار از روی `domain.ts` با `scripts/gen-laravel-schema.mjs`) + ۵۶ مدل Eloquent + سیدر ایمپورت کل کاتالوگ از JSON (خروجی دیتابیس واقعی با `scripts/export-seed-json.mjs` ↔ `database/seeders/data/*.json`) | ✅ انجام شد |
| ۳ | **API فروشگاه و حساب کاربری** (~۷۰ روت): OTP/توکن، کاتالوگ و جستجو (موتور فیلتر/مرتب‌سازی کامل)، سبد مهمان/کاربر، کوپن، آدرس، چک‌اوت/پرداخت سندباکس/کیف‌پول، علاقه‌مندی/مقایسه/اعلان، دیدگاه/پرسش، تیکت، CMS — با ۲۲ FormRequest فارسی، پورت یک‌به‌یک DTOها و منطق سرویس‌ها، میدلور توکن و نقش، رویدادهای اعلان/لاگ | ✅ انجام شد (تأیید ایستا با scripts/php-sanity.mjs؛ اجرای نهایی روی PHP) |
| ۴ | **API پنل‌ها** (~۴۰ روت): ادمین / فروشنده / انباردار + گزارش‌ها و تنظیمات | ⏳ |
| ۵ | اتصال فرانت با `NEXT_PUBLIC_API_URL` (rewrites)، سرویس php-fpm+nginx و MySQL در docker-compose، تست دود روی لاراول، README | ⏳ |

## چرا در سندباکس Arena لاراول «اجرا» نمی‌شود؟

این محیط فقط **Node 22** دارد: PHP/Composer/MySQL/Docker ندارد و شبکه‌اش به Packagist
(مخزن پکیج‌های PHP) بسته است؛ بنابراین اجرای `composer install` اینجا ممکن نیست.
به همین دلیل فاز ۱ دیتابیس واقعی را روی بک‌اند فعلی (Next.js) زنده کردیم تا سایت از همین
حالا از روی دیتابیس کار کند، و پروژه لاراول در `backend/` ساخته می‌شود تا روی هر محیط
استاندارد PHP (سیستم شما یا Docker) با یک دستور بالا بیاید:

```bash
cd backend && composer install && php artisan migrate --seed && php artisan serve --port=8000
```

## اصول پیاده‌سازی لاراول

1. **قرارداد ثابت:** پاسخ‌ها دقیقاً `{ data }` / `{ data, meta }` و خطاها `422 { message, errors }` فارسی — فرانت بدون هیچ تغییری کار می‌کند.
2. **اسکیمای یکسان:** نام جداول و ستون‌ها مطابق `src/types/domain.ts` (۱۲ ماژول، فیلدبه‌فیلد) — مایگریشن‌ها از روی همین تایپ‌ها تولید می‌شوند.
3. **سید یکسان:** داده‌های `src/server/db/data/*` به JSON خروجی داده می‌شود و Seeder لاراول همان‌ها را ایمپورت می‌کند؛ کالاها/دسته‌ها/برندها/فروشنده‌ها/کاربران دمو (`09120000001..4` با رمز `123456`) و سفارش‌های نمونه دقیقاً همان می‌شوند.
4. **نقش‌ها:** `super_admin | admin | seller | customer | warehouse` + توکن Bearer (معادل Sanctum).
5. **دیتابیس:** پیش‌فرض SQLite (توسعه سریع) و آماده MySQL برای پروداکش (docker-compose).
